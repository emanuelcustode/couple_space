# 💑 CoupleSpace

Eine native Apple App für Paare — gemeinsamer Kalender, geteilte Notizen und ein gemeinsamer Space für zwei.

---

## 📱 Plattformen

- iOS 17+
- macOS 14+

---

## ✨ Features

- **Dashboard** — Wochenübersicht mit Events und Notizen auf einen Blick
- **Kalender** — Gemeinsamer Kalender mit Event-Verwaltung
- **Notizen** — Geteilte Notizen als Cards
- **CoupleSpace** — Zwei Personen, ein gemeinsamer Space

---

## 🛠 Tech Stack

- **SwiftUI** — UI Framework

---

## 🚀 Getting Started

### Voraussetzungen

- Xcode 15+
- Apple Developer Account (für CloudKit)
- macOS Ventura oder neuer

### Installation

1. Repository klonen:
```bash
git clone https://github.com/deinname/couple-space.git
```

2. Projekt in Xcode öffnen:
```bash
cd couple-space
open couple_space.xcodeproj
```

3. In Xcode unter **Signing & Capabilities** dein Team auswählen

4. App starten mit `Cmd + R`
